## 1. DeepWrite 是什么

DeepWrite 是一款面向小说、故事和剧本创作的本地写作软件。它把作品正文、人物设定、剧情设计、写作方法、参考素材和 AI 智能体放在同一个工作台中。

它与普通 AI 聊天工具最大的区别是：

- 普通聊天工具通常只回答问题，DeepWrite 可以围绕当前作品持续工作。
- 你可以把人物、剧情、大纲和正文分开管理，不必全部塞进一次对话。
- 智能体可以读取当前作品允许读取的内容，也可以调用已绑定的技能和素材。
- 智能体提出正文修改后，你可以先看修改内容，再决定接受或拒绝。
- 作品、技能和素材保存在本机文件夹中，方便备份、迁移和继续编辑。

可以把 DeepWrite 理解为一个“有资料室、有写作流程、还有多个 AI 助手的写作工作室”。

## 2. 先认识主界面

DeepWrite 的主界面通常分为三栏。

### 2.1 左侧：导航与资源树

左侧用于选择功能和管理内容，主要包括：

- **新建对话**：清空当前对话，开始一次新的交流，不会删除作品内容。
- **工作目录**：设置新作品、技能库和素材库默认保存到哪里。
- **模型配置**：添加 AI 模型、测试连接、设置默认模型。
- **学习仿写**：分析参考作品，提取素材、剧情方法和文风方法。
- **智能体团队**：为主智能体配置专项子智能体。
- **创作空间**：存放短篇、剧本和长篇作品。
- **技能库**：存放“怎么写”的方法。
- **素材库**：存放“写什么、参考什么”的资料。

鼠标移到作品、资料库或条目旁边时，通常会出现 `+` 或更多操作按钮。新建、改名、绑定、导出、移除等操作大多从这里进入。

### 2.2 中间：智能体对话区

中间区域用于和当前智能体交流。你可以直接用日常语言下达任务，例如：

> 请根据当前人物设定，设计一个发生在雨夜便利店的冲突场景。先给方案，不要写正文。

或者：

> 请读取当前小节要求和上一节人物状态，续写 1500 字。保持第一人称，不要提前揭示凶手。

选择不同的作品节点时，中间的智能体也会跟着变化。例如选择“人物”时使用人物智能体，选择“剧情”时使用剧情智能体，选择正文小节时使用正文写作智能体。

输入框附近通常还可以：

- 选择模型；
- 选择思考等级或温度；
- 输入 `/` 调用当前可用技能；
- 输入 `@` 引用当前可用素材；
- 附加文件或引用右侧正文选区；
- 停止正在生成的内容。

### 2.3 右侧：内容阅读与编辑区

右侧显示当前选中的人物、剧情、正文、技能或素材。你可以自己输入和修改，也可以让智能体提出修改。

如果智能体要修改文稿，界面会显示修改建议或差异对比：

- 选择 **接受并保存**：修改写入本机文件；
- 选择 **拒绝**：保留原文，不写入本机；
- 如果开启了自动审批，智能体的修改可能自动进入保存队列，新手建议先使用“请求批准”。

## 3. 第一次使用前的准备

### 3.1 选择工作目录

工作目录是 DeepWrite 保存新作品和资料库的总文件夹。

操作步骤：

1. 点击左侧 **工作目录**。
2. 点击 **选择工作目录**。
3. 选择一个容易找到、空间充足的文件夹。
4. 确认后返回主界面。

建议单独建立一个文件夹，例如：

```text
文档/DeepWrite工作区
```

软件会在工作目录中分别保存书籍、素材库和技能库。切换工作目录不会自动搬动已经打开的旧作品。

> **截图占位 04｜选择工作目录**  
> 建议截图范围：工作目录页面，包含当前路径和“选择工作目录”按钮。  
> 建议文件名：`images/04-选择工作目录.png`

### 3.2 建议检查两个常规设置

进入左下角的设置入口，在 **常规** 中检查：

- **权限**：新手建议选择“请求批准”，这样智能体修改文件前由你确认。
- **自动保存**：建议开启。停止输入片刻后，软件会自动保存到本机。

即使开启自动保存，重要作品也建议定期复制整个作品文件夹做备份。

## 4. 模型配置

模型可以理解为智能体的“大脑”。没有可用模型，智能体就无法正常完成分析和创作。

DeepWrite 提供两类配置方式：

1. **DeepWrite 官方国内模型**：按页面说明添加令牌并启用模型，配置相对简单。
2. **自定义模型配置**：使用你自己从模型服务商获得的 API Key。

### 4.1 最省事的方式：使用官方模型

1. 打开设置。
2. 在左侧找到 **模型与用量 → DeepWrite 官方国内模型**。
3. 按页面提示获取并填写令牌。
4. 启用需要的模型。
5. 返回 **模型配置**，确认模型已经出现在列表中。

令牌和 API Key 都相当于模型服务的密码，不要截图发给陌生人，也不要粘贴到公开文档中。

### 4.2 添加自定义模型

1. 点击左侧 **模型配置**，或者进入 **设置 → 自定义模型配置**。
2. 点击 **添加模型**。
3. 依次填写模型信息。

各字段的简单解释如下：

| 字段 | 怎么填写 |
| --- | --- |
| 名称 | 你自己容易识别的名称，例如“我的写作模型” |
| Provider | 选择模型服务商；不确定时根据服务商文档选择 |
| 模型 ID | 服务商提供的准确模型名称，不能凭感觉填写 |
| API 类型 | 按服务商接口类型选择，例如 OpenAI、Anthropic 或 Google 对应类型 |
| API 地址 | 服务商提供的接口地址；使用预设服务商时通常会自动填写 |
| API Key | 从模型服务商控制台创建的密钥 |
| 模型模式 | 支持推理的模型选“思考模式”；普通创作模型可选“不思考模式” |
| 思考等级 | 越高通常分析更充分，但可能更慢、消耗更多 |
| 温度 | 越低越稳定，越高越有变化；不懂时使用默认值即可 |

4. 点击 **测试当前填写**。
5. 测试成功后，点击 **应用到配置**。
6. 在模型卡片上点击 **设为默认**。
7. 最后点击页面底部的 **保存模型配置**。

请注意，“应用到配置”和“保存模型配置”是两步。只点前者就关闭页面，设置可能还没有最终保存。

### 4.3 模型怎么选

新手不需要一开始配置很多模型。先准备一个稳定可用的模型即可。

- 人物、剧情、长篇结构：适合使用理解能力和推理能力较强的模型。
- 正文创作、润色、文风模仿：适合使用中文表达自然的模型。
- 简单整理、分类：可以使用速度快、价格较低的模型。

对话开始前可以在中间区域再次选择模型。这里的选择只影响当前任务，不必每次都修改全局默认模型。

## 5. 创作空间、技能库和素材库的关系

这是使用 DeepWrite 最重要的概念。

### 5.1 一句话理解

- **创作空间**：你的作品正在写什么。
- **素材库**：给作品提供哪些内容和参考。
- **技能库**：要求智能体按照什么方法工作。

例如你正在写一篇都市悬疑短篇：

- 创作空间里有这篇短篇的人物、剧情和正文；
- 素材库里有城市地点、职业资料、案件梗、人物原型和参考片段；
- 技能库里有悬疑节奏、伏笔设置、对白润色和分节写作方法。

### 5.2 它们怎样连在一起

```text
素材库（提供内容） ──┐
                     ├── 绑定到作品 ── 当前阶段智能体 ── 生成或修改作品
技能库（提供方法） ──┘
```

只创建资料库并不等于当前作品会自动使用它。你还需要在新建作品时选择资料库，或者在作品的更多菜单中打开 **技能库绑定**、**素材库绑定**。

绑定以后，智能体也不会把所有内容一次性读完。它会根据当前阶段、读取范围和你的任务，选择需要的技能或查询相关素材。这能减少无关内容干扰。

### 5.3 分类的作用

素材库分为：

- **人设素材库**：人物原型、关系、身份、性格、人物弧；
- **梗素材库**：创意、钩子、反转、核心设定；
- **剧情素材库**：剧情结构、导语、情节点、场景链；
- **正文素材库**：参考片段、描写摘录、对白表达；
- **其他素材库**：无法归入以上类型的资料。

技能库分为：

- **通用技能库**：诊断、整理、润色等多个阶段都能使用的方法；
- **剧情设计技能库**：冲突、节奏、转折、伏笔、大纲等方法；
- **文风写作技能库**：句式、对白、描写和正文写作方法；
- **其他技能库**：自定义专项方法。

分类不是为了好看，而是帮助软件在正确阶段提供正确资料。

### 5.4 单独绑定与分组绑定

新建作品时有两种选择方式：

- **按分类选择**：逐个选择人设、梗、剧情、正文等资料库，适合资料库不多时。
- **选择分组**：提前把一组常用资料库组合起来，一次完成绑定，适合经常写同一题材时。

素材库和技能库由短篇、剧本、长篇共同使用。你可以把同一个通用技能库绑定给多个作品。

## 6. 新建并创作短篇

### 6.1 新建短篇

1. 在左侧找到 **创作空间**。
2. 点击标题旁边的 `+` 或新建菜单。
3. 选择 **新建作品**。
4. 在“创作类型”中选择 **短篇**。
5. 输入书名。
6. 选择分类，例如世情、追妻、科幻、悬疑或其他。
7. 按需绑定技能库和素材库。暂时没有资料库也可以不绑定，之后再补。
8. 点击 **创建书籍**。

> 建议截图范围：新建作品窗口，显示短篇、书名、分类、技能库和素材库区域。  
> 建议文件名：`images/08-新建短篇.png`

### 6.2 推荐的短篇写作顺序

短篇推荐按以下顺序推进：

```text
人物 → 剧情设计 → 导语设计 → 剧情细化 → 其他已启用剧情阶段 → 正文目录 → 分节正文
```

不同版本或自定义设置下，“剧情”中显示的阶段可能不同。以左侧实际显示的节点为准。

#### 第一步：写人物

1. 展开刚创建的短篇。
2. 点击 **人物**。
3. 在中间告诉人物智能体你的想法。

示例：

> 我想写一个 8000 字的都市悬疑短篇。主角是深夜便利店店员，表面冷淡，实际上害怕独处。请设计主角、失踪顾客和一名误导调查的配角。先说明人物功能和关系，再写人物卡。

4. 查看智能体写入建议。
5. 内容合适就接受并保存，不合适可以拒绝，或者要求它修改。

人物不要只写年龄和外貌。至少要有目标、恐惧、秘密、行为习惯、关系和最终变化。

#### 第二步：写剧情

依次点击剧情下的阶段，让剧情智能体完成对应内容。

可参考以下任务：

- 剧情设计：`根据人物设定设计主线冲突、三次升级、关键反转和结局。先保证因果成立。`
- 导语设计：`为这个故事写三个不同方向的开篇钩子，每个不超过 150 字，并说明各自制造的阅读期待。`
- 剧情细化：`把已确认的剧情拆成可以直接写作的场景链，标出每场的目标、阻力、信息和结尾推动。`
- 叙事视角：`比较第一人称和第三人称限知的效果，并为本故事确定统一的视角规则。`
- 大纲：`整理为 5 个小节，每节给出标题、目标字数、出场人物、关键情节和结尾钩子。`

每次进入一个新阶段，先让智能体读取已经确认的人物和前序剧情，再继续设计。不要同时要求它重做人物、剧情和整篇正文。

#### 第三步：建立正文小节

1. 点击作品下的 **正文**。
2. 点击正文旁边的 `+`，手动新建小节；或者让正文专家根据已有大纲批量建立小节。
3. 为每个小节设置清楚的标题和字数要求。

示例：

> 请读取当前剧情规划，根据已经确认的小节安排，一次建立全部空白小节。只建立目录，先不要写正文。

#### 第四步：逐节写正文

1. 选择一个具体小节。
2. 告诉智能体本节要完成什么。
3. 让它读取相邻前文、人物设定和本节剧情要求。
4. 生成后检查人物行为、时间、物品位置和结尾承接。
5. 接受并保存修改，再写下一节。

示例：

> 请写当前小节，目标 1500 字。承接上一节结尾，完成“顾客留下明天日期的小票”这一情节点。保持第一人称限知，不要在本节揭示真相。

如果只想改一段，最好选中右侧对应文字，再让智能体修改，避免整节重写。

## 7. 新建并创作剧本

### 7.1 新建剧本

1. 在左侧 **创作空间** 旁点击新建。
2. 选择 **新建作品**。
3. 在“创作类型”中选择 **剧本**。
4. 输入剧本名称并选择分类。
5. 绑定需要的技能库和素材库。
6. 点击 **创建剧本**。

> **截图占位 10｜新建剧本**  
> 建议截图范围：新建作品窗口，创作类型选择“剧本”。  
> 建议文件名：`images/10-新建剧本.png`

### 7.2 剧本与短篇有什么不同

剧本的基本流程仍然是“人物 → 剧情 → 正文”，但正文按 **剧集** 管理，不是普通小说小节。

剧本写作时更要明确：

- 每集的目标和结尾钩子；
- 场次、地点和时间；
- 角色动作与对白；
- 哪些信息能拍出来，哪些只是人物内心；
- 集与集之间的人物状态和连续性。

### 7.3 推荐的剧本写作步骤

1. 在 **人物** 中建立主要角色、关系和人物弧。
2. 在 **剧情** 中确定全剧主线、分集推进、每集冲突和季终兑现。
3. 在 **大纲或承担分集规划的剧情阶段** 中列出每集标题、目标、场次和结尾钩子。
4. 点击 **正文**，手动新建剧集，或让正文专家按规划批量创建空白剧集。
5. 选择具体剧集，让分集写手一次只写当前一集。
6. 完成后检查对白是否可表演、动作是否可拍摄、场景转换是否清楚。

示例任务：

> 请根据已确认的全剧规划，建立 8 集空白剧集，每集写明标题和目标字数，不要开始写正文。

> 请创作当前这一集。使用“场次标题 + 动作描述 + 角色对白”的剧本格式，共 6 场。结尾停在主角发现监控时间被改过，不要提前解释原因。

> 请检查当前剧集：只修正无法拍摄的心理描写、人物称呼不一致和场次时间错误，不改变剧情。

### 7.4 剧本的连续创作习惯

每完成一集，建议留下简单的集末状态：谁知道了什么、人物关系如何变化、关键物品在哪里、还有哪些悬念未解决。这样下一集更不容易出现前后矛盾。

## 8. 新建并创作长篇

长篇比短篇多了一套专门的结构和连续性管理。不要一开始就让智能体“直接写完整本小说”，最好先把世界、人物、故事线和章卡搭起来。

### 8.1 新建长篇

1. 在左侧 **创作空间** 旁点击新建。
2. 选择 **新建作品**。
3. 在“创作类型”中选择 **长篇**。
4. 输入书名并选择长篇题材。
5. 绑定需要的技能库和素材库。
6. 点击 **创建长篇**。

> **截图占位 11｜新建长篇**  
> 建议截图范围：新建作品窗口，创作类型选择“长篇”，并显示绑定区域。  
> 建议文件名：`images/11-新建长篇.png`

### 8.2 长篇的五类核心工作区

长篇主要围绕以下内容工作：

- **世界观**：世界规则、地点、组织、制度、科技或超自然规则；
- **人物**：人物档案、关系、当前状态和变化轨迹；
- **故事线/剧情**：分卷、剧情点、故事情节、事件关系、叙事落点和伏笔；
- **正文**：章卡和对应章节正文；
- **连续性账本**：已经发生并确认的事实、未解决问题和章节接续信息。

### 8.3 推荐的长篇搭建顺序

```text
世界观分类与条目
    ↓
人物类型与人物档案
    ↓
分卷与剧情点
    ↓
故事事件、情节关系、叙事落点与伏笔
    ↓
章卡
    ↓
单章正文
    ↓
连续性检查与提交
```

#### 第一步：建立世界观

先建立分类，再在分类中添加具体条目。例如：

```text
世界规则
├── 记忆交易规则
├── 使用代价
└── 禁止事项

地点
├── 雾港旧城
└── 海上档案馆
```

世界观只写会影响人物选择和剧情的内容。没有必要一开始就写百科全书。

#### 第二步：建立人物

先确定人物类型，例如主角、重要配角、对手、组织人物，再创建人物档案。

每个主要人物建议至少写清楚：

- 当前身份与处境；
- 核心目标、恐惧和秘密；
- 与其他人物的关系；
- 能做什么、不能做什么；
- 开篇状态和预期人物弧。

#### 第三步：建立分卷、剧情点与章卡

- **分卷**：长篇的大阶段，例如“第一卷：入局”。
- **剧情点**：这一阶段要解决的一组主要冲突。
- **故事情节/事件**：具体发生了什么。
- **章卡**：某一章真正要写的任务单。

新手可以先做到“每章一张章卡”。章卡中最好写清楚：

- 本章目标；
- 承接上一章的状态；
- 出场人物和地点；
- 关键事件与选择；
- 要透露的信息；
- 人物状态变化；
- 结尾钩子；
- 目标字数。

#### 第四步：写单章正文

1. 选中具体章卡或章节正文。
2. 让智能体读取本章章卡、相关人物、必要世界观、上一章正文和接续状态。
3. 一次只写当前章。
4. 查看提案，确认后选择 **接受并保存**。
5. 完成后让连续性智能体检查事实、人物状态、物品和未回收伏笔。

示例：

> 请写当前章，目标 2500 字。严格执行当前章卡；读取上一章结尾、林默和苏遥的人物档案，以及“灰潮规则”。本章只让主角发现规则漏洞，不揭示幕后组织。

#### 第五步：使用连续性账本

长篇最容易出现的错误是“上一章受伤，下一章突然没事”“某人知道了不该知道的信息”“伏笔忘了回收”。连续性账本就是用来管理这些事实。

每章完成后建议核对：

- 时间和地点；
- 人物当前伤势、情绪、关系；
- 人物已经知道的信息；
- 关键物品的位置和归属；
- 已埋伏笔、待回收伏笔；
- 下一章必须承接的内容。

长篇结构一旦被连续性事实引用，部分内容可能会锁定，不能随意删除或改动。这是为了保护已经写出的章节不被后来的结构修改破坏。

## 9. 建设技能库

技能不是素材，也不是作品内容。技能是给智能体的工作说明，告诉它遇到某类任务时应该怎么做。

### 9.1 新建技能库

1. 在左侧找到 **技能库**。
2. 点击标题旁的 `+`。
3. 选择 **新建技能库**。
4. 输入名称，例如“我的悬疑写作技能”。
5. 选择类型：通用、剧情设计、文风写作或其他。
6. 创建完成后，在技能库旁打开更多菜单。
7. 选择 **新建条目**，输入技能名称。
8. 在右侧编辑器中填写技能内容并保存。

官方内置技能通常是只读的。要写自己的方法，请新建个人技能库。

> **截图占位 15｜新建技能库和技能条目**  
> 建议截图范围：技能库的新建菜单、类型选择，以及一个展开后的技能库。  
> 建议文件名：`images/15-新建技能库.png`

### 9.2 一个好技能应该写什么

一个实用技能至少包含五部分：

1. **用途**：什么时候使用；
2. **准备**：开始前要读取什么；
3. **步骤**：按什么顺序工作；
4. **输出**：最终交付什么格式；
5. **限制**：哪些事情不要做。

可以直接复制下面的模板，再按自己的需要修改：

```markdown
---
name: 悬疑章节节奏检查
description: 当用户要求检查悬疑章节的节奏、信息投放或结尾钩子时使用。
---

# 技能名称：悬疑章节节奏检查

## 什么时候使用

当用户要求检查悬疑章节的节奏、信息投放或结尾钩子时使用。

## 开始前读取

- 当前章节全文
- 当前章卡或本节剧情要求
- 上一章结尾
- 与本章有关的人物设定

## 工作步骤

1. 找出本章读者最想知道的问题。
2. 标出每次新增信息、误导和反转。
3. 检查中段是否连续出现说明而缺少行动。
4. 检查结尾是否产生新的问题或迫使人物做出选择。
5. 先列问题，再提出最小修改方案。

## 输出要求

- 先给出三条最重要的问题。
- 每条问题引用对应段落或情节。
- 给出可执行修改建议。
- 除非用户明确要求，不要整章重写。

## 限制

- 不改变已经确认的真相。
- 不提前公开后续章节的信息。
- 不为了制造反转而让人物突然失去正常判断。
```

### 9.3 技能库的建设方法

不要一开始建立几十个空泛技能。最好的方法是从真实写作问题中积累。

建议先建立这些常用技能：

- 人物动机检查；
- 剧情因果检查；
- 开篇钩子设计；
- 分节/分集写作；
- 对白校准；
- 去除重复表达；
- 连续性检查；
- 完稿校对。

每次使用后，如果结果不理想，就修改技能中的步骤和限制。经过多次调整的技能，才是真正属于你的写作方法。

### 9.4 把技能绑定给作品

新建作品时可以直接绑定。已有作品的操作方法：

1. 在左侧找到作品名称。
2. 打开作品右侧的更多菜单。
3. 选择 **技能库绑定**。
4. 按分类选择技能库，或者选择技能分组。
5. 点击 **保存绑定**。

绑定后，在对话框中输入 `/` 可以查看当前智能体可调用的技能。如果找不到某个技能，先检查技能库类型、作品绑定和当前智能体读取范围。

## 10. 建设素材库

素材库用于保存可供创作参考的内容。它不是把所有资料混在一个大文档里，而是把资料按用途和条目整理好，让智能体需要时再查询。

### 10.1 新建素材库

1. 在左侧找到 **素材库**。
2. 点击标题旁的 `+`。
3. 选择 **新建素材库**。
4. 输入资料库名称。
5. 选择类型：人设、梗、剧情、正文或其他。
6. 根据需要填写题材等信息。
7. 创建后，通过资料库的更多菜单选择 **新建条目**。
8. 输入条目名称，在右侧编辑内容并保存。

> **截图占位 16｜新建素材库和素材条目**  
> 建议截图范围：新建素材库窗口，以及展开后显示“库介绍”和多个条目的资源树。  
> 建议文件名：`images/16-新建素材库.png`

### 10.2 素材条目应该怎么写

每个条目只解决一个主题，标题要能搜索。不要使用“资料1”“灵感2”这类看不出内容的名称。

例如，人设素材可以这样写：

```markdown
# 深夜便利店店员原型

## 可用身份

- 24 小时便利店夜班店员
- 熟悉固定顾客的购买习惯
- 能接触监控、收银记录和遗失物

## 可产生的冲突

- 顾客失踪，但收银记录显示对方第二天仍来过
- 主角私自保留遗失物，无法向警方解释
- 监控与主角记忆不一致

## 使用提醒

- 不要把职业写成万能调查权限。
- 店员能看到店内信息，但不能轻易获得警方内部资料。
```

正文参考素材可以这样写：

```markdown
# 克制的雨夜环境描写参考

## 想保留的特点

- 少用“阴森、恐怖”等直接形容词
- 通过灯管噪声、雨水反光和湿衣服表现不适
- 环境描写必须推动人物注意力或行动

## 禁止照搬

- 不复制参考作品的原句
- 不复制专有角色、地点和情节
```

### 10.3 素材库建设的四条原则

1. **一条一主题**：一个人物原型、一个地点、一个梗分别建条目。
2. **标题可搜索**：标题直接说明内容。
3. **区分事实和灵感**：考据资料注明来源，灵感注明可改动部分。
4. **避免大量无关原文**：只保存真正会使用的内容，长资料先整理摘要。

每个素材库和技能库条目有长度限制。资料特别长时，拆成多个条目比全部塞进一篇更好。

### 10.4 把素材库绑定给作品

1. 打开作品名称旁的更多菜单。
2. 选择 **素材库绑定**。
3. 分别选择人设、梗、剧情、正文或其他素材库。
4. 点击 **保存绑定**。

在对话输入框中输入 `@`，可以引用当前可用素材。没有手动 `@` 时，智能体也可能按任务查询已关联素材，但明确点名通常更可靠。

## 11. 使用学习仿写

学习仿写用于分析参考小说，从中提取可复用素材、剧情方法和文风方法。它的目标是总结方法，不是复制原文。

请只上传你有权使用的文本。不要把受版权保护的作品直接改名后当成自己的内容发布。

### 11.1 准备样本

点击左侧 **学习仿写**。每轮可以上传 1—5 篇正文，支持：

- TXT；
- Markdown；
- PDF；
- Word（`.doc`、`.docx`）。

建议选择风格或题材相近的样本。差异特别大的作品混在一起，会让总结结果互相冲突。

> **截图占位 17｜学习仿写完整页面**  
> 建议截图范围：顶部样本文档、三个学习阶段、结果预览和右侧学习智能体。  
> 建议文件名：`images/17-学习仿写页面.png`

### 11.2 三个学习阶段

学习仿写分为三个阶段，可以分别运行。

#### 阶段一：素材拆分

点击 **一键拆素材**。智能体会从样本中整理：

- 梗；
- 人设；
- 剧情设计；
- 导语设计；
- 剧情细化；
- 优秀正文片段。

结果可以分别保存到人设、梗、剧情和正文素材库。

#### 阶段二：剧情学习

点击 **一键学习剧情设计**。智能体会总结结构、冲突、转折和节奏方法，生成剧情设计技能与剧情细化技能。

结果应保存到 **剧情技能库**。

#### 阶段三：文风学习

点击 **一键文风学习**。智能体会分析句式、对白、情绪和收束方式，生成可供分节写手使用的文风技能。

结果应保存到 **文风技能库**。

### 11.3 完整操作步骤

1. 点击 **+ 上传正文**，添加 1—5 个样本文档。
2. 在右侧选择要使用的模型。
3. 点击一个一键学习任务。
4. 等待运行结束。切换到其他页面不会中断后台任务。
5. 在左侧结果预览中检查并手动修正内容。
6. 为当前阶段选择目标素材库或技能库；没有合适的库时，可在下拉框中选择新建资料库并填写名称。
7. 点击 **确认落盘**。
8. 选择保存方式：
   - **追加落盘**：把新结果接到已有内容后面；
   - **覆盖落盘**：替换同一栏目的旧结果；
   - 如果没有匹配条目，两种方式都会新建条目。

新手第一次保存建议使用“追加落盘”，确认整理无误后再考虑覆盖。

### 11.4 自定义学习任务

点击 **自己输入任务**，可以让学习智能体重点分析某个问题，例如：

> 重点比较这三篇样本的前三段如何建立钩子。不要总结人物和完整剧情，只输出可以复用的开篇步骤与常见错误。

### 11.5 新建学习是什么意思

点击 **新建学习** 会清空当前上传文档、三阶段预览和聊天记录，但不会删除已经保存到技能库或素材库的内容。

## 12. 使用智能体团队

智能体团队是“主智能体 + 专项子智能体”的协作方式。主智能体负责理解你的总任务，必要时把其中一部分交给子智能体。

例如：

- 剧情主智能体负责总体方案；
- 时间线检查子智能体专门找时间矛盾；
- 伏笔审阅子智能体专门检查埋设与回收；
- 对白校准子智能体专门检查人物说话方式。

### 12.1 什么时候需要智能体团队

以下情况适合使用：

- 长篇结构复杂，一个智能体容易漏掉问题；
- 你经常重复做同一种专项检查；
- 希望把“创作”和“审阅”交给不同角色；
- 已经有成熟技能，想把它转换成专项助手。

如果只是写一个简单短篇，不必一开始就配置很多子智能体。

### 12.2 新增子智能体

1. 点击左侧 **智能体团队**。
2. 选择创作类型：短篇、剧本或长篇。
3. 选择要配置的主智能体。
   - 短篇/剧本通常有人设、剧情、正文三个主智能体；
   - 长篇包括世界观、人物、剧情、正文统筹、单章写手和连续性。
4. 点击 **新增子智能体**。
5. 填写名称、能力说明和系统提示词。
6. 选择模型方式：
   - **跟随主智能体**：简单、推荐；
   - **单独配置模型**：专项任务使用另一模型。
7. 确认子智能体处于启用状态。
8. 点击 **保存智能体团队**。长篇页面对应按钮为 **保存长篇智能体团队**。

> **截图占位 19｜智能体团队配置**  
> 建议截图范围：创作类型、主智能体标签、一个展开编辑的子智能体卡片。  
> 建议文件名：`images/19-智能体团队配置.png`

### 12.3 三个字段怎么写

#### 名称

要短而明确，例如：

- 时间线核验员；
- 人物动机审阅；
- 对白校准；
- 伏笔清单检查。

#### 能力说明

这是给主智能体看的“调用说明”，要写清楚什么时候该找它。

示例：

> 检查章节中的日期、先后顺序、人物移动时间和昼夜变化。当任务涉及跨章连续性或时间跳跃时调用。

#### 系统提示词

这是子智能体实际工作的规则。示例：

```markdown
你是时间线核验子智能体。

职责：检查用户指定内容中的日期、时刻、事件先后顺序、移动耗时和人物年龄。

工作步骤：
1. 读取主智能体交给你的目标内容和必要的前后章节。
2. 按发生顺序列出事件。
3. 标出确定冲突、可能冲突和缺少信息三类问题。
4. 对每个问题给出最小修改建议。

限制：
- 不擅自重写正文。
- 不新增未确认的世界规则。
- 没有证据时明确写“信息不足”，不要猜测。

交接：把问题清单和修改建议返回给主智能体。
```

### 12.4 从技能库加载

短篇和剧本团队支持从技能库加载子智能体草稿。适合把已经成熟的技能转换成专项角色。

1. 选择主智能体。
2. 点击 **从技能库加载**。
3. 选择技能条目。
4. 让系统生成子智能体草稿。
5. 检查名称、能力说明和提示词。
6. 加入当前主智能体草稿。
7. 最后仍要点击 **保存智能体团队** 才会生效。

### 12.5 重要边界

- 子智能体不会继承主智能体的完整对话和提示词。
- 子智能体不能继续创建自己的子智能体。
- 子智能体是否直接修改文件，取决于它的提示词、可用工具和审批设置。
- 长篇子智能体不能绕过用户审批。
- 子智能体越多不一定越好。名称和能力重叠时，主智能体反而难以选择。

推荐每个主智能体先配置 1—3 个职责明显不同的子智能体。

## 13. 日常写作、保存与导出

### 13.1 自己写和让智能体写可以交替进行

你可以直接在右侧编辑器输入，也可以让智能体修改。推荐的配合方式是：

1. 自己写出核心想法或粗稿；
2. 让智能体检查具体问题；
3. 查看差异；
4. 只接受真正有帮助的修改；
5. 自己完成最后判断。

### 13.2 看懂保存状态

右侧编辑器可能显示：

- **等待自动保存**：你刚停止输入，软件稍后保存；
- **正在保存到本机**：正在写入文件，不要立即关闭软件；
- **已保存到本机**：保存完成；
- **有未应用修改**：自动保存关闭，需要点击应用或立即保存；
- **智能体运行中，暂停编辑**：为了避免版本冲突，暂时不能手动改。

### 13.3 新建对话不会删除正文

点击 **新建对话** 只会开始新的聊天。已经保存的人物、剧情、正文、技能和素材不会被删除。

当对话越来越长、智能体开始混淆旧要求时，可以新建对话，再用一句话说明当前任务。

### 13.4 重新绑定资料库

写作过程中可以修改作品的技能库和素材库绑定：

1. 打开作品更多菜单；
2. 选择技能库绑定或素材库绑定；
3. 调整选择；
4. 保存绑定；
5. 新一轮对话会使用新的资料范围。

### 13.5 导出作品

从作品名称旁的更多菜单选择 **导出** 或 **导出正文**，再按窗口提示选择范围和目标位置。

导出前建议：

- 确认所有编辑状态都显示已保存；
- 检查智能体提案是否仍在等待审批；
- 浏览章节顺序和标题；
- 长篇检查是否漏选章节；
- 导出后打开文件抽查开头、中间和结尾。

> **截图占位 20｜作品更多菜单与导出**  
> 建议截图范围：作品名称旁的更多菜单，显示结构管理、技能库绑定、素材库绑定和导出。  
> 建议文件名：`images/20-作品菜单与导出.png`

### 13.6 备份

DeepWrite 的项目使用本机文件夹保存。最简单的备份方法是定期复制整个工作目录到：

- 移动硬盘；
- 另一个本机文件夹；
- 可信的同步盘。

不要只复制导出的正文。完整作品文件夹还包含人物、剧情、结构和资料库绑定信息。

“从创作空间移除”和“永久删除”不同：

- **移除**：只从当前列表取消登记，本地文件仍保留，以后可以重新打开；
- **永久删除**：删除整个项目文件夹，通常无法恢复。

看到删除确认窗口时，请认真核对操作名称和目标作品。

## 14. 常见问题

### 14.1 智能体不能发送消息

依次检查：

1. 是否已经配置模型；
2. 模型是否测试连接成功；
3. 是否设为默认模型，或当前对话是否选择了模型；
4. API Key 是否有效、是否有余额；
5. 网络是否能访问对应模型服务。

### 14.2 建了技能库，但智能体看不到技能

检查：

1. 技能库是否绑定到当前作品；
2. 技能库类型是否适合当前阶段；
3. 当前智能体是否有技能读取范围；
4. 技能条目是否已经保存；
5. 是否需要新建一轮对话再试。

### 14.3 建了素材库，但智能体没有使用

先确认作品已经完成素材库绑定。然后在任务中直接说明要查询的内容，或者输入 `@` 引用具体素材。素材标题越清楚，越容易找到。

### 14.4 智能体改错了正文

- 还没接受时，直接拒绝提案；
- 已经接受但编辑器仍可撤销时，立即使用撤销；
- 让智能体基于最新原文做局部修改，不要再次整章重写；
- 重要修改前先备份作品文件夹。

### 14.5 AI 写出的内容前后矛盾

把任务缩小，并明确要求它读取：

- 当前人物档案；
- 当前剧情/章卡；
- 上一节或上一章；
- 人物状态或连续性账本；
- 与本章有关的世界观规则。

长篇每章结束后及时更新连续性信息，比完稿后统一修正更省力。

### 14.6 学习仿写结果太杂

- 一轮只上传题材或风格相近的样本；
- 使用“自己输入任务”限定分析目标；
- 先在预览中删除空泛内容，再落盘；
- 不要把素材总结保存进技能库，也不要把方法说明保存进素材库。

### 14.7 应该用追加落盘还是覆盖落盘

- 旧内容仍然有价值：选择追加；
- 新结果是旧结果的完整修订版：选择覆盖；
- 不确定：先追加，检查后再手动整理。

## 15. 推荐的新手创作路线

如果你第一次使用 DeepWrite，可以照下面的顺序完成一个小项目。

### 第一天：完成准备

1. 选择工作目录。
2. 配置一个模型并测试成功。
3. 开启自动保存，权限选择“请求批准”。
4. 新建一个通用技能库和一个素材库。

### 第二天：完成短篇结构

1. 新建一部 5000—8000 字短篇。
2. 写主要人物。
3. 完成剧情设计、导语和剧情细化。
4. 建立 3—5 个正文小节。

### 第三天：完成初稿

1. 一次写一个小节。
2. 每节结束后检查人物状态和承接点。
3. 不满意时只修改具体问题，不反复整篇重写。

### 第四天：整理自己的资料库

1. 把这次真正有用的方法整理成技能条目。
2. 把可复用的人物原型、地点和梗整理成素材条目。
3. 删除没有实际帮助的空泛内容。
4. 导出正文并备份整个工作目录。

完成这一轮后，再尝试剧本、长篇、学习仿写和智能体团队。先建立稳定的小流程，比一次配置所有功能更容易得到好结果。

## 附录：高质量任务的通用写法

向智能体下达任务时，尽量包含以下五项：

```text
任务：要做什么
范围：只处理哪里
依据：需要读取哪些内容
要求：字数、格式、视角、风格
限制：哪些内容不能改变或提前揭示
```

示例：

> 任务：润色当前小节。  
> 范围：只处理右侧选中的三段。  
> 依据：读取主角人物卡和当前章卡。  
> 要求：保持第一人称，减少重复形容词，加强动作和对白。  
> 限制：不新增情节，不改变人物已经知道的信息，不修改其他小节。

任务越清楚，智能体越容易给出可控、可检查的结果。
